# Edilson Digital Studio — código organizado

O mesmo site autoral, agora com arquivos fáceis de localizar e ler.

- `index.html`: estrutura, textos e acessibilidade.
- `styles.css`: design, responsividade e animações de CSS.
- `script.js`: Canvas, efeitos, navegação e formulário do WhatsApp.

Abra `index.html` no navegador ou use a extensão Live Server no VS Code.
Não é necessário instalar dependências.

O formulário do WhatsApp abre uma conversa; não confirma agendamentos automaticamente.
