# Edilson Digital Studio — Portfólio completo

Versão do estúdio com seção **Projetos Selecionados** e quatro links reais.

## Arquivos

- `index.html` — estrutura sem HTML compactado em uma linha.
- `styles.css` — identidade visual, responsividade e animações.
- `script.js` — partículas em Canvas, transições, navegação e formulário do WhatsApp.

## Links do portfólio

- Naldo: https://naldo-studio-revestimento.vercel.app/
- ALBA: https://alba-floristeria.vercel.app/
- BRASA (versão cinematográfica): https://brasa-campolim.vercel.app/brasa.html
- VELOCITY: https://velocity-3d.vercel.app/

## Visualizar

Abra a pasta no VS Code e use **Live Server** ou abra o `index.html` diretamente no Chrome. Fontes externas dependem de internet.

## Publicar no seu repositório atual

O repositório remoto não foi modificado automaticamente. Faça backup dos arquivos atuais, substitua `index.html`, `styles.css` e `script.js` pelos deste pacote e confira no navegador. Depois, no terminal da pasta já conectada ao GitHub:

```powershell
git status
git add index.html styles.css script.js README.md
git commit -m "Publica portfolio com quatro projetos"
git push origin main
```

A Vercel conectada à branch `main` publicará a atualização quando o deploy concluir.

**Nota:** BRASA e ALBA são projetos conceituais. O site principal do estúdio já publicado não foi alterado por esta entrega até você enviar os arquivos ao GitHub.
